# AGENTS.md

Instructions for AI coding agents working in this repository.

## Project

`dema-strat` is a research repo for backtesting a DEMA-based intraday strategy
on OHLCV tick data. Python 3.14, managed by `uv`. The library code under
`src/dema_strat/` is a thin package; the active work happens in notebooks
under `src/`.

## Layout

```
pyproject.toml          # uv project, Python 3.14
uv.lock                 # locked dependency graph
.python-version         # 3.14
src/
  dema_strat/           # importable package
    __init__.py
    loader.py           # OHLCV CSV/Parquet loader (float32, VWAP, cache)
  constants.py          # MARGIN, CASH, trading SESSIONS
  main.ipynb            # primary strategy notebook
  vectorbt_test.ipynb   # vectorbt port of the backtest
  utils.ipynb           # shared helpers
  f0_raw/main.ipynb     # raw data exploration
  example/              # reference notebooks (monte_carlo, main)
  backtest_results.db   # SQLite of backtest outputs (generated, not source)
```

## Tooling

- Use `uv` for everything: `uv sync`, `uv run <cmd>`, `uv add <pkg>`.
- Do not use `pip`, `python -m venv`, or `poetry`. `uv.lock` is the source of
  truth for dependencies.
- Python is pinned to 3.14 via `.python-version` and `requires-python`.

## Dependencies

Core: `pandas`, `numpy`, `vectorbt`, `plotly`, `matplotlib`, `pyarrow`,
`nbformat`.

The `backtesting` library was removed; do not re-add it. New backtest work
goes through `vectorbt` (see `src/vectorbt_test.ipynb`).

## Code conventions

- The package under `src/dema_strat/` is importable as `dema_strat` (see
  `pyproject.toml` `[project.scripts]`). Re-export public APIs from
  `__init__.py` — `loader.py` already does this for `load_ohlcv`,
  `vbt_frame`, `free`.
- No comments in code unless the user asks for them.
- Match the style already in the file you are editing (imports, typing,
  naming).
- Notebooks are first-class deliverables. Keep cell outputs that document a
  result; strip outputs from cells that just import or set config.

## Data loading

Always go through `dema_strat.load_ohlcv`:

```python
from dema_strat import load_ohlcv, vbt_frame
df = load_ohlcv("path/to/ticks.csv", verbose=True)
df_vbt = vbt_frame(df)  # float64 copy for vectorbt
```

The loader writes a Parquet cache next to each CSV (`<stem>__cache_v1.parquet`)
keyed on file mtime + size. Delete the cache to force a rebuild. Do not parse
CSVs with raw `pd.read_csv` in notebooks — use the loader so the cache and
float32 layout are preserved.

## Backtest conventions

- Margin and starting cash are in `src/constants.py` (`MARGIN = 0.01`,
  `CASH = 10_000`). Import them; do not redefine.
- Trading sessions are defined in `SESSIONS` in the same file. Add new
  sessions there, not inline.
- Strategy parameter grids are run as loops that call `free(*objs)` between
  iterations to keep RAM flat — follow the pattern in
  `src/vectorbt_test.ipynb`.

## Working with notebooks

- Open/run with `uv run jupyter lab` (or `uv run jupyter notebook`).
- When you edit a notebook, run the affected cells before reporting the
  change as done.
- `backtest_results.db` is regenerated by runs; it is checked in for
  convenience but safe to delete.

## Git

- Do not commit unless asked.
- `.gitignore` currently only ignores `__pycache__`. Large generated
  artifacts (e.g. fresh `backtest_results.db`, Parquet caches) are fine to
  leave out of commits if they are regenerated cheaply.
- Commit messages: short, imperative, lower-case subject line.

## Things to avoid

- Re-adding `backtesting` to dependencies.
- Hard-coded paths under `/home/chris/...` in committed code; use relative
  paths from `src/` or accept the path as a parameter.
- `print` debugging in library code (`loader.py`); keep stdout noise in
  notebooks behind `verbose=True`.
